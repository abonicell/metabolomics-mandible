# Metabolomics-mandible

This code is linked to the published article: Chiappetta, M.E., Roggia, E., Alladio, A., Bonicelli, A., & Procopio, N. (2025). Forensic Metabolomics: Enhancing PMI Estimation through Porcine Bone Tissue Profiling. J. Proteome Res. 2025, 24, 5498−5510. https://doi.org/10.1021/acs.jproteome.5c00250.

All raw metabolomics data is available on MetabolomicsWorkbench: GCdata: https://dev.metabolomicsworkbench.org:22222/data/DRCCMetadata.php?Mode=Study&StudyID=ST003863&Access=LjzS9350, and LCdata: https://dev.metabolomicsworkbench.org:22222/data/DRCCMetadata.php?Mode=Study&StudyID=ST003862&Access=DloB9219
